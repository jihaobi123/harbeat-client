本目录保存历史模型评测、人工复核、试听和设备验证资料。结果只对报告记录的数据、版本和测试范围有效；“测试通过”不代表新 APK、后端、RK 全链路已实现。

正式模型和 NAS 发布合同从 [preprocessing](../preprocessing/README.md) 查看；研究代码从 [research](../research/README.md) 查看。不要将历史报告中的接口、服务路径或安装命令作为第二版部署依据。

本轮不删除模型/训练证据，不将本机未跟踪的报告、音频或数据集自动上传 Git。需要共享具体评审资料时应单独确认范围和资源渠道。
