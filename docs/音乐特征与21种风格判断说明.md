# HARBEAT 音乐特征分析与21种风格判断说明

> 本文说明系统已经能分析什么、需要增加哪些时频特征，以及这些特征如何组合成21种音乐风格判断。本文中的频率范围是第一版工程分析区间，不是绝对的乐器定义；正式阈值需要通过人工标注音频校准。

## 一、整体判断方法

系统不使用“检测到某个乐器就直接判断风格”的单一规则，而是分四步完成：

1. **已有分析确定音乐坐标**：BPM、Beat、Downbeat、小节、十六步网格、调性、能量和分轨；
2. **时频分析确定声音属性**：基频、谐波、起音、衰减、滑音、失真和音色家族；
3. **音乐特征层形成事实**：Snare落点、Kick模板、Hat密度、Bass行为、人声和制作质感；
4. **风格层组合证据**：对21种风格分别评分，输出Top 3、依据和不确定项。

可以简单理解为：

```text
已有分析回答：声音什么时候出现、落在第几拍？
时频分析回答：这个声音听起来像什么、怎样变化？
风格分析回答：这些位置和音色共同更接近哪种风格？
```

例如：

```text
Snare主要在第3拍
+ Hi-hat包含Tresillo和短Roll
+ Kick高度切分
+ Bass存在连续滑音
+ 整体制作偏暗
→ Drill得分高于Trap和Grime
```

## 二、当前已经具备的基础分析

| 已有结果 | 实际含义 | 在风格判断中的作用 |
|---|---|---|
| BPM | 歌曲速度 | 判断House、Afrobeats、Grime等速度范围 |
| 半速/倍速关系 | 70与140、75与150是否属于同一速度框架 | Trap、Drill、Grime的重要基础 |
| Beat | 每一拍的时间 | 所有节奏落点分析的基础 |
| Downbeat | 每小节第一拍 | 判断Snare位于第2、3还是第4拍 |
| 16步小节网格 | 鼓点位于1 e & a中的具体位置 | 判断四踩、Dembow、Jersey、Tamborzão |
| 调性/Camelot | 和声中心与大小调 | 主要服务接歌，对风格仅作辅助 |
| 能量曲线 | 段落的平稳、柔和或爆发 | 辅助判断Rage、R&B、Drop等 |
| Demucs Drums Stem | 相对独立的鼓轨 | 鼓点和鼓件音色分析 |
| Demucs Bass Stem | 相对独立的低音轨 | Sub、808、滑音和Log Drum分析 |
| Demucs Vocals Stem | 相对独立的人声轨 | Rap、演唱、人声密度和Vocal Chop |
| Demucs Other Stem | Synth、和声和其他配器 | Rage Synth、Jazz/Soul和声、采样质感 |
| Kick/Snare/Hi-hat事件 | 基础鼓点时间 | Backbeat、Half-time、四踩等节奏语法 |
| Bass音高轨迹 | Bass音高随时间的变化 | Bass滑音、Pitch Drop和Bass旋律 |
| 人声区间 | 人声出现和退出时间 | R&B、Trap-Soul、Jersey Club及接歌 |
| 基础频谱描述 | 明亮度、失真、Lo-fi等连续值 | 整体制作质感的初步证据 |

当前分析的主要优势是“位置”；主要缺口是“音色身份”和“制作听感”。新增时频分析用于补足这一部分。

## 三、时频分析架构

### 1. 分析不同音轨

| 音轨 | 主要分析内容 |
|---|---|
| Drums Stem | Kick、Snare/Clap/Rim、Hat、Cymbal、手鼓和有音高打击乐 |
| Bass Stem | Sub、808候选、Bass滑音、Bass失真、低频打击乐和Log Drum候选 |
| Vocals Stem | Rap、演唱、Vocal Chop和人声密度 |
| Other Stem | Synth、和声、采样、原声/电子配器和制作质感 |
| 原始混音 | 验证分轨结果，避免把串轨误认为真实特征 |

部分声音会被Demucs拆到两条Stem。例如808的起音可能进入Drums Stem，持续低频进入Bass Stem。因此，关键特征必须进行跨Stem验证。

### 2. 分析时间窗口

| 对象 | 建议截取范围 |
|---|---|
| Kick、Snare、Hat等短鼓击 | 起音前20ms至起音后500ms |
| Bass、808、Log Drum | 起音前30ms至起音后2秒 |
| 人声、和声、Synth和制作质感 | Downbeat对齐的8或16小节 |

### 3. 提取的时频信息

每个声音事件不只统计高中低频，而是提取：

- 基频F0及音高置信度；
- 2F0、3F0、4F0等谐波；
- 频谱峰数量和稳定性；
- 频谱重心、带宽、平坦度和对比度；
- 起音时间、峰值时间和衰减时间；
- 前段与后段能量比例；
- Pitch Drop和Pitch Slide；
- 波形削顶和失真谐波；
- 事件在小节中的位置；
- 同类事件跨小节的重复规律。

### 4. 多分辨率分析

- 鼓轨和Other轨保留44.1kHz，以保留Hat、Ride、Crash和Synth高频信息；
- 短窗STFT分析鼓击起音；
- 长窗STFT分析低频、谐波和衰减；
- 候选区段 pYIN 分析 Bass 基频、Voiced Probability、Pitch Drop 和滑音，频谱峰仅作降级 fallback；
- 8/16小节频谱与Embedding分析整体制作和配器。

## 四、具体音乐特征及判定依据

### 1. Kick

**主要音轨：** Drums Stem。

**判定依据：**

- 主要低频能量约集中在30–150Hz；
- 起音短促；
- 2–6kHz可能存在Click或攻击声；
- 低频能量通常快速衰减；
- 与现有Kick事件时间一致。

**输出特征：**

- `kick_sub_strength`：Kick低频强度；
- `kick_attack`：攻击性；
- `kick_decay`：衰减长度；
- `electronic_kick_tendency`：电子Kick倾向；
- `acoustic_kick_tendency`：原声Kick倾向。

### 2. Sub Bass与808候选

**主要音轨：** Bass Stem；Drums Stem检查起音；原始混音复核。

808不是固定频率。系统先检测当前音符的基频F0，再观察相对于F0的谐波和时间变化。

**判定依据：**

- 常见低频主体位于约35–90Hz，但允许随音高变化；
- 能检测到稳定基频；
- 2F0、3F0、4F0存在可解释谐波；
- 起音后可能出现Pitch Drop；
- 低频Decay较长；
- 可以形成音符、旋律或滑音；
- 失真版本会在500–2000Hz出现更多谐波；
- 起音可能与Kick重合或紧密关联。

**排除关系：**

- 只有Drums Stem出现短低频，更像普通Kick；
- Bass Stem只有持续低频，没有起音、Pitch Drop或Kick关系，更像普通Sub；
- 谐波丰富且拨弦瞬态明显，更像电贝司；
- 只有滑音但缺少808音色证据，只能确认`bass_slide`。

**输出特征：**

- `sub_bass`；
- `bass_sustain`；
- `bass_pitch_drop`；
- `bass_slide`；
- `bass_distortion`；
- `kick_bass_alignment`；
- `808_timbre_candidate`。

### 3. Log Drum候选

**主要音轨：** Bass Stem为主，Drums Stem辅助。

**判定依据：**

- 约40–250Hz存在有音高低频事件；
- 起音比普通Bass更短促、更打击化；
- 可能在起音后快速变调；
- 衰减通常比普通Kick长，但比铺底Sub更像独立音符；
- 经常落在Kick之间；
- 在1a、2&、3a、4&等空隙形成回答；
- 多个事件组成低频旋律。

**输出特征：**

- `pitched_low_percussion`；
- `bass_percussive_attack`；
- `bass_reply_pattern`；
- `low_frequency_melody`；
- `log_drum_timbre_candidate`。

### 4. Snare、Clap与Rim/Snap

**主要音轨：** Drums Stem。

| 音色家族 | 判定依据 |
|---|---|
| Full Snare | 约150–300Hz鼓体，加1–8kHz噪声尾，衰减中等 |
| Wide Clap | 高频噪声更宽，常出现多个相隔10–50ms的瞬态 |
| Rim/Snap | 短促、窄带共振明显、衰减快 |

**输出特征：**

- `full_snare`；
- `wide_clap`；
- `short_rim_snap`；
- `snare_family`。

后续风格优先使用家族和落点，不要求逐次完全区分。

### 5. Closed Hat、Open Hat、Ride与Crash

**主要音轨：** Drums Stem，保留44.1kHz。

| 音色家族 | 判定依据 | 位置辅助 |
|---|---|---|
| Closed Hat | 4kHz以上噪声强，衰减短 | 连续八分或十六分 |
| Open Hat | 高频能量持续，衰减明显更长 | 常位于反拍 |
| Ride | 持续金属谐波，事件重复稳定 | 常形成Swing或八分律动 |
| Crash | 宽频金属爆发，长衰减 | 常位于乐句第一拍或Drop |

**输出特征：**

- `short_metallic_hit`；
- `sustained_metallic_hit`；
- `open_hihat_candidate`；
- `ride_candidate`；
- `crash_candidate`。

### 6. Tom、Conga与Bongo

**主要音轨：** Drums Stem。

**判定依据：**

- 约80–800Hz存在明确基频；
- 具有谐波和Pitch Drop；
- 打击包络短促；
- Conga/Bongo通常具有更明显中高频攻击声；
- Tom通常低频鼓体更重。

**输出特征：**

- `pitched_drum_low`；
- `pitched_drum_mid`；
- `hand_drum_family`；
- `tom_candidate`；
- `conga_bongo_candidate`。

### 7. Shaker与Tambourine

**主要音轨：** Drums Stem。

**判定依据：**

- 3–12kHz连续噪声；
- 高频起音密度高；
- 呈八分或十六分周期；
- Shaker单次起音较细；
- Tambourine通常频谱更宽，并带较明显撞击成分。

**输出特征：**

- `continuous_high_percussion`；
- `shaker_layer`；
- `tambourine_candidate`。

### 8. Cowbell、Clave、Agogô与Woodblock

**主要音轨：** Drums Stem或Other Stem。

**判定依据：**

- 约500Hz–5kHz存在稳定窄带频谱峰；
- 多个事件的基频与谐波位置相近；
- 起音短促；
- 跨小节形成重复八分、十六分或旋律动机。

**输出特征：**

- `tonal_percussion`；
- `tonal_percussion_motif`；
- `cowbell_clave_candidate`；
- `agogo_woodblock_candidate`。

Memphis Trap主要使用“重复有音高打击动机”，不要求绝对确认Cowbell。

### 9. Hi-hat Roll

**判定依据：**

- 连续事件属于高频金属家族；
- 相邻事件间隔明显短于普通八分或十六分；
- 形成三连音、三十二分或短时加速；
- 只在短时间内密集出现，而不是整首持续高密度噪声。

**输出特征：**

- `hat_roll_density`；
- `triplet_roll`；
- `thirty_second_roll`。

### 10. Ghost Note

**判定依据：**

- 与主Snare频谱相似；
- 音量显著低于主Snare；
- 出现在主Snare前后或切分位置；
- 跨多个小节重复。

**输出特征：**

- `ghost_snare`；
- `ghost_note_density`。

### 11. 原声鼓、电子鼓与采样循环

| 类型 | 判定依据 |
|---|---|
| 原声鼓倾向 | 同类鼓击之间存在自然频谱、起音和衰减变化，动态差异较大 |
| 电子鼓倾向 | 同类事件频谱高度一致，起音和衰减稳定，音色集中或合成感明显 |
| 采样循环倾向 | 多小节局部波形和频谱高度重复，连背景噪声也重复 |

**输出特征：**

- `acoustic_drum_tendency`；
- `electronic_drum_tendency`；
- `sampled_loop_tendency`。

### 12. Lo-fi与采样质感

**主要音轨：** Drums Stem、Other Stem和原始混音。

**判定依据：**

- 高频衰减明显；
- 存在稳定噪声底；
- 频谱带宽受限；
- 可能存在Wow/Flutter；
- 多小节采样纹理重复；
- 瞬态被压软。

**输出特征：**

- `lofi_texture`；
- `sample_texture`；
- `vinyl_noise_candidate`；
- `bandwidth_reduction`。

### 13. 失真

**判定依据：**

- 基频上方出现大量新增谐波；
- 频谱趋于密集；
- 波形峰值削平；
- Crest Factor下降；
- 原本低频的声音在500Hz–5kHz出现明显能量。

**输出特征：**

- `bass_distortion`；
- `drum_distortion`；
- `overall_distortion`。

### 14. Rage式高频Synth

**主要音轨：** Other Stem。

**判定依据：**

- 500Hz–8kHz存在强烈持续谐波；
- 频谱重心较高；
- 谐波和失真密集；
- 音符或和弦攻击明显；
- 段落能量高；
- 乐句第一拍出现强频谱爆发；
- 与Trap鼓型同时存在。

**输出特征：**

- `bright_aggressive_synth`；
- `dense_synth_harmonics`；
- `synth_distortion`；
- `phrase_energy_burst`。

### 15. Jazz/Soul和声倾向

**主要音轨：** Other Stem和原始混音。

**判定依据：**

- CQT/Chroma中的音高集合；
- 和弦变化频率；
- 多音同时出现程度；
- 大小调色彩变化；
- 七和弦和扩展音倾向；
- 与Jazz/Soul参考片段的和声相似度。

**输出特征：**

- `harmonic_complexity`；
- `chord_change_rate`；
- `jazz_harmony_candidate`；
- `soul_harmony_candidate`。

### 16. Rap、演唱与Vocal Chop

**主要音轨：** Vocals Stem。

| 类型 | 判定依据 |
|---|---|
| Rap倾向 | 音高稳定段短、音节密度高、节奏对齐明显 |
| 演唱倾向 | 音高持续较长、旋律变化清晰、稳定元音更多 |
| Vocal Chop | 100–800ms短人声片段跨小节重复，并与Beat对齐 |

**输出特征：**

- `rap_likelihood`；
- `singing_likelihood`；
- `melodic_rap_likelihood`；
- `vocal_chop_repetition`；
- `vocal_density`。

## 五、节奏模板的具体判定依据

所有模板都在连续至少8小节中计算，并同时考虑目标落点命中率、非目标落点、跨小节稳定性和鼓点质量。

| 节奏特征 | 具体判定 |
|---|---|
| Backbeat | Snare/Clap稳定命中第2、4拍 |
| Half-time | 主Snare主要命中第3拍 |
| Four-on-the-floor | Kick稳定命中第1、2、3、4拍 |
| Jersey Club | Kick接近1、2、3、3a、4&，Snare围绕第3拍和3a |
| Tamborzão | Kick接近1、2&、3&、4，Snare/Clap在2、4附近回应 |
| Dembow | Kick与Snare/Rim形成稳定交错重音 |
| Tresillo | 鼓点形成3-3-2类重音分布，允许不同相位变体 |
| Two-step | Snare在2、4，Kick避开稳定四踩并在反拍切分 |
| Drill Hat | Tresillo、三连音、十六分和短Roll组合 |
| Breakbeat | 保留2/4 Snare骨架，但Kick/Snare出现切碎、提前、延后和Fill |
| Swing | 反拍事件稳定晚于理论二等分位置 |
| Afro Syncopation | 连续高频打击层、稀疏Kick与多层Percussion交错 |

## 六、风格分析的组合原则

每种风格的判断由四部分组成：

1. **核心节奏**：Snare位置、Kick模板、Hat密度和Groove；
2. **Bass行为**：Sub、滑音、失真、Kick/Bass关系和空隙回应；
3. **时频音色**：鼓件家族、电子/原声、采样、Lo-fi和Synth；
4. **人声与和声**：Rap、演唱、Vocal Chop、Jazz/Soul和声。

默认权重范围：

| 特征组 | 权重范围 |
|---|---:|
| 节奏位置与模板 | 40%–50% |
| 时频音色 | 20%–30% |
| Bass行为 | 10%–25% |
| 人声、和声与制作 | 10%–25% |

House、Jersey Club、UK Garage等节奏辨识度高的风格提高节奏权重；Drill和Amapiano提高Bass权重；R&B、Jazz-HipHop、Disco、Rage和Trap-Soul提高人声、和声与制作权重。

缺失特征不等于不存在。模型没有运行或分轨质量差时，该项不参与评分，不作为反对证据。

## 七、Freestyle Battle / Cypher九种风格

### 1. Boombap

**核心条件：**

- Snare稳定在第2、4拍；
- Kick以第1拍为中心，并在2&、3&等位置切分；
- Hi-hat以八分为主；
- 可存在Swing，但不要求每首都明显。

**时频补充：**

- Snare鼓体较厚；
- 鼓组具有采样或重复循环倾向；
- 高频带宽收窄、瞬态压软或存在Lo-fi纹理。

**排除与区分：**

- 如果第3拍Snare、十六分Hat和强Sub更明显，转向Trap；
- 如果Jazz和声与Swing更强，转向Jazz-HipHop；
- 如果Snare明显靠后并以演唱为主，转向Neo-Soul。

**判断式：**

```text
2/4 Backbeat + Hip-Hop切分Kick + 八分Hat/Swing + 采样或Lo-fi倾向
```

### 2. Trap

**核心条件：**

- 主Snare在第3拍；
- Hi-hat为八分或十六分，并出现短Roll；
- Kick高度切分；
- 低频强，Bass与Kick存在明显关系。

**时频补充：**

- 强Sub和较长Bass Decay；
- Pitch Drop或808音色候选；
- 可存在Bass滑音，但不是必须；
- 鼓组和Bass偏电子化。

**排除与区分：**

- Bass滑音、Drill Hat和暗色制作同时明显时转向Drill；
- 重复有音高打击动机和Lo-fi明显时转向Memphis Trap；
- 明亮激进Synth和高失真明显时转向Rage；
- 演唱与R&B和声明显时转向Trap-Soul。

**判断式：**

```text
第3拍Snare + 十六分Hat/Roll + 切分Kick + 强Sub/808候选
```

### 3. Funk

**核心条件：**

- Snare在第2、4拍；
- Hi-hat以带重音的十六分为主；
- Kick围绕第1拍并大量使用反拍；
- Bass与Kick、Snare形成互锁。

**时频补充：**

- 鼓组事件之间存在自然变化，偏原声；
- Bass具有中频谐波和清晰音符边界；
- 可存在有音高打击乐，但Cowbell不是必要条件。

**排除与区分：**

- 如果稳定四踩和反拍Open Hat更强，转向Disco或House；
- 如果鼓点被切碎并形成采样Break循环，转向Breakbeat。

**判断式：**

```text
2/4 Backbeat + 十六分切分Hat + 高切分Kick + 鼓Bass互锁 + 原声乐队倾向
```

### 4. Breakbeat

**核心条件：**

- 保留第2、4拍Snare骨架；
- Kick不形成四踩；
- Kick/Snare出现提前、延后、切碎和Fill；
- Break模式跨小节重复。

**时频补充：**

- 鼓组具有采样循环倾向；
- 可存在黑胶噪声、高频带宽收窄和Lo-fi纹理；
- 小节末常有密集鼓击或Roll。

**排除与区分：**

- 如果鼓型更规整、Swing明显且Kick以第1拍为中心，偏Boombap；
- 如果Two-step和Swing Hat更稳定，偏UK Garage。

**判断式：**

```text
2/4骨架 + 非四踩 + 碎拍/Fill + Break采样循环
```

### 5. Soul / Neo-Soul

**核心条件：**

- Snare/Rim在第2、4拍并略靠后；
- Hi-hat带Swing；
- Kick较稀疏；
- Groove整体松弛。

**时频补充：**

- Snare/Rim攻击较软；
- 频谱偏温暖、失真较低；
- 演唱占比高；
- 和声复杂度与Soul参考相似度高。

**排除与区分：**

- 如果Hip-Hop采样鼓更强而人声不是主要依据，偏Boombap；
- 如果Jazz和声、Ride/Brush倾向更强，偏Jazz-HipHop；
- 如果鼓组更现代、平滑且演唱主导，偏R&B。

**判断式：**

```text
靠后的2/4 Backbeat + Swing + 稀疏Kick + 温暖和声 + 演唱
```

### 6. Jazz-HipHop

**核心条件：**

- Hip-Hop式第2、4拍Snare；
- Ride/Hi-hat具有Swing或三连音律动；
- Kick在第1拍和反拍之间变化。

**时频补充：**

- Ride/Brush候选；
- 原声或采样乐器倾向；
- 和声复杂度高；
- 与Jazz参考片段的和声和整体音色相似。

**排除与区分：**

- 如果采样鼓强但和声较简单，偏Boombap；
- 如果演唱和松弛和声比Hip-Hop鼓更突出，偏Neo-Soul。

**判断式：**

```text
Hip-Hop Backbeat + Swing/三连音 + Jazz和声与采样/原声倾向
```

### 7. Afro / Afrobeats

**核心条件：**

- BPM通常位于90–120；
- Kick稀疏并切分；
- Rim/Clap常强调第3拍；
- 多层打击乐交错；
- 高频打击层持续运行。

**时频补充：**

- Shaker类连续高频噪声；
- 手鼓家族和有音高打击乐候选；
- Bass具有旋律性和切分，但不以低频打击回答为唯一核心。

**排除与区分：**

- 如果1/3 Kick、2/4 Clap和低频空隙回答更明显，偏Amapiano；
- 如果Dembow更明确，偏Dancehall；
- 如果连续四踩更强，偏Afro-house/House倾向。

**判断式：**

```text
90–120 BPM + 稀疏切分Kick + 多层Percussion + 连续高频打击 + Afro整体听感
```

### 8. House

**核心条件：**

- Kick稳定命中第1、2、3、4拍；
- Snare/Clap在第2、4拍；
- Open Hat位于反拍；
- 模式连续多个小节稳定。

**时频补充：**

- Kick和鼓组偏电子化；
- Open Hat具有长高频衰减；
- Bass和Synth呈电子舞曲制作倾向。

**排除与区分：**

- 如果乐队Bass、吉他、弦乐和原声配器倾向更强，偏Disco；
- 如果Dembow和拉丁Percussion更强，偏Moombahton；
- 如果1/3 Kick和低频空隙回答明显，偏Amapiano。

**判断式：**

```text
稳定四踩 + 2/4 Clap + 反拍Open Hat + 电子制作
```

### 9. Grime / UK Hip-Hop

**核心条件：**

- 约140/70速度框架；
- 主Snare在第3拍；
- Kick稀疏并不规则切分；
- Hi-hat断续并保留空拍。

**时频补充：**

- Kick较短促；
- 金属感打击乐候选；
- Bass和整体制作偏暗；
- Rap倾向明显。

**排除与区分：**

- 如果Bass滑音和Drill Hat更明显，偏Drill；
- 如果2/4 Snare、Two-step和Swing Hat更明显，偏UK Garage。

**判断式：**

```text
140/70框架 + 第3拍Snare + 稀疏切分Kick + Hat留空 + 暗色金属制作
```

## 八、派对 / 酒吧十二种风格

### 1. R&B / Contemporary R&B

**核心条件：**

- 可使用第2、4拍Backbeat，也可使用第3拍Half-time；
- Kick较稀疏；
- Hi-hat带Swing；
- 鼓组为人声留出空间。

**时频补充：**

- 鼓组攻击柔和；
- 演唱占比高，音高持续明显；
- 和声复杂度较高；
- 制作平滑、失真和攻击性较低。

**排除与区分：**

- 如果Trap骨架、808和第3拍Snare更突出，偏Trap-Soul；
- 如果Snare明显靠后、Soul和声和原声感更强，偏Neo-Soul。

**判断式：**

```text
柔和Backbeat/Half-time + 稀疏Kick + Swing + 演唱 + 平滑和声
```

### 2. Disco

**核心条件：**

- 稳定四踩；
- Snare/Clap在第2、4拍；
- Open Hat位于四个反拍；
- Groove稳定并适合连续舞蹈。

**时频补充：**

- Bass具有乐队演奏和中频谐波；
- 镲片衰减较长；
- 吉他、弦乐、铜管或原声乐队倾向；
- 事件之间存在自然动态变化。

**排除与区分：**

- 如果电子Kick、Synth Bass和电子制作更强，偏House；
- 如果Kick切分而非稳定四踩，且鼓Bass互锁更强，偏Funk。

**判断式：**

```text
四踩 + 2/4 Snare + 反拍Hat + 乐队Bass与原声配器
```

### 3. Jersey Club

**核心条件：**

- Kick接近1、2、3、3a、4&；
- Snare围绕第3拍与3a；
- 短小循环高度重复；
- Hi-hat通常不是主要驱动。

**时频补充：**

- Kick/Sub起音重；
- 存在100–800ms短人声片段重复；
- Vocal Chop与Beat高度对齐。

**排除与区分：**

- 如果稳定四踩更强，偏House；
- 如果Tamborzão和密集Percussion更强，偏Baile Funk。

**判断式：**

```text
Jersey Kick模板 + 第3拍附近Snare + 短循环 + Vocal Chop候选
```

### 4. Drill

**核心条件：**

- 主Snare在第3拍；
- Hi-hat具有Tresillo、三连音或变化Roll；
- Kick高度切分；
- Kick与Bass节奏紧密关联。

**时频补充：**

- Bass存在连续滑音；
- 强Sub和808音色候选；
- Bass可能带失真；
- 整体制作偏暗。

**排除与区分：**

- 没有明显Bass滑音但Trap基础骨架成立，偏Trap；
- 140框架、Hat断续且Bass不强调滑音，偏Grime。

**判断式：**

```text
第3拍Snare + Drill Hat + 高切分Kick + Bass滑音 + 暗色制作
```

### 5. Amapiano

**核心条件：**

- Kick常位于第1、3拍；
- Clap/Rim常位于第2、4拍；
- Shaker类高频层连续运行；
- Bass事件在Kick之间的空隙回答。

**时频补充：**

- 低频事件具有明确音高和打击性起音；
- 可能出现快速Pitch Drop；
- 低频事件组成旋律；
- Log Drum音色候选作为额外证据。

**排除与区分：**

- 如果Bass主要为旋律铺底而不是空隙低频回答，偏Afrobeats；
- 如果稳定四踩和普通电子Bass更强，偏House。

**判断式：**

```text
1/3 Kick + 2/4 Clap + 连续Shaker + 有音高低频空隙回答 + Amapiano听感
```

### 6. Moombahton

**核心条件：**

- Dembow骨架明确；
- Kick可四踩或突出第1、3拍；
- Open Hat位于反拍；
- 鼓组兼具House和拉丁律动。

**时频补充：**

- Kick和Bass偏电子化；
- 手鼓家族与连续高频打击层；
- 整体具有EDM制作倾向。

**排除与区分：**

- 如果制作更有机、Kick更稀疏，偏Dancehall；
- 如果Tamborzão和失真低频更强，偏Baile Funk。

**判断式：**

```text
Dembow + House式Kick/反拍Hat + 拉丁打击 + 电子舞曲制作
```

### 7. Dancehall

**核心条件：**

- Dembow或Tresillo明确；
- Kick稀疏并避免持续四踩；
- Snare/Rim与Kick交错；
- Groove相对松弛。

**时频补充：**

- Kick较短促；
- 手鼓家族和Shaker候选；
- 低频与打击乐较有机，电子高频相对较少。

**排除与区分：**

- 如果House Kick、反拍Hat和EDM制作更强，偏Moombahton；
- 如果Afro多层Percussion和连续高频层更突出，偏Afrobeats。

**判断式：**

```text
Dembow/Tresillo + 稀疏Kick + Snare/Rim交错 + 有机加勒比制作
```

### 8. Baile Funk

**核心条件：**

- Tamborzão Kick模板明显；
- Snare/Clap位于第2、4拍或邻近切分；
- Percussion密度高；
- 小节内存在Ghost Kick或额外切分。

**时频补充：**

- 低频和Kick具有明显失真谐波；
- 存在重复有音高高频打击乐；
- Agogô、Cowbell、Whistle候选作为额外证据。

**排除与区分：**

- 如果Dembow和House电子制作更强，偏Moombahton；
- 如果Jersey Kick模板和Vocal Chop更强，偏Jersey Club。

**判断式：**

```text
Tamborzão + 2/4 Snare回应 + 密集Percussion + 失真低频 + 有音高高频动机
```

### 9. Memphis Trap

**核心条件：**

- Trap式第3拍Snare；
- Hi-hat为十六分并插入短Roll；
- Kick/Sub高度切分。

**时频补充：**

- 强Sub或808候选；
- 存在重复有音高打击乐动机；
- 整体偏暗、Lo-fi或采样化；
- 高频带宽可能收窄。

**排除与区分：**

- 没有有音高动机和Lo-fi时，偏普通Trap；
- Synth高亮、失真和能量爆发更强时，偏Rage。

**判断式：**

```text
Trap骨架 + 重复有音高打击动机 + 强Sub + 暗色Lo-fi
```

### 10. Rage

**核心条件：**

- Trap式第3拍Snare；
- Hi-hat持续八分或十六分并加入Roll；
- Kick/Bass切分；
- 段落能量高。

**时频补充：**

- Other Stem存在明亮激进Synth；
- 500Hz–8kHz谐波和失真密集；
- 乐句第一拍具有能量和频谱爆发；
- Bass可能明显失真。

**排除与区分：**

- 如果Synth不突出而暗色Bass和滑音更强，偏Drill；
- 如果有音高打击动机和Lo-fi更强，偏Memphis Trap；
- 如果只是基础Trap鼓型且制作不激进，偏Trap。

**判断式：**

```text
Trap骨架 + 明亮激进Synth + 失真谐波 + 高能量爆发
```

### 11. UK Garage

**核心条件：**

- Snare/Clap位于第2、4拍；
- Kick避开稳定四踩；
- Two-step模式稳定；
- Hi-hat具有Swing；
- Bass切分。

**时频补充：**

- Kick短促；
- Sub Bass明显但通常不强调长808 Decay；
- Shaker或连续高频打击层；
- 电子Club制作。

**排除与区分：**

- 如果140/70 Half-time和暗色金属制作更强，偏Grime；
- 如果Break采样循环和碎鼓更强，偏Breakbeat。

**判断式：**

```text
2/4 Snare + Two-step Kick + Swing Hat + 切分Sub Bass
```

### 12. Trap-Soul

**核心条件：**

- Trap/Half-time骨架；
- 主Snare通常位于第3拍；
- Hi-hat比普通Trap更稀疏；
- Roll较少；
- Kick/Bass给人声留出空间。

**时频补充：**

- Bass较柔和，失真较低；
- 演唱概率高；
- R&B/Soul和声倾向明显；
- 整体攻击性低于Trap和Rage。

**排除与区分：**

- 如果Rap和密集Hat更强，偏Trap；
- 如果没有明显Trap骨架而Backbeat、Swing和演唱更强，偏R&B。

**判断式：**

```text
Trap骨架 + 稀疏Hat/Bass + 演唱 + R&B和声 + 柔和制作
```

## 九、输出与置信度原则

最终不只输出一个风格名称，而是返回：

- 21种风格Top 3；
- 每个结果的核心节奏依据；
- Bass、时频音色、人声和和声依据；
- 明确的反对证据；
- 缺失或不可用的特征；
- 第一名与第二名分差；
- 是否需要人工复核。

示例：

```text
1. Drill          0.80
2. Trap           0.55
3. Grime          0.39

支持Drill：
- 140/70速度框架
- 主Snare在第3拍
- Hi-hat具有Tresillo和短Roll
- Kick高度切分
- Bass存在连续滑音
- 整体制作偏暗

不确定项：
- 可以确认Bass滑音，但808音色只有候选证据
- 金属打击乐证据较弱
```

系统不得把最高分自动归一化成100%。未经人工验证集校准前，`score`表示相对匹配程度，不表示真实概率。

## 十、最终原则

1. 节奏落点和跨小节稳定性是风格判断的第一依据；
2. 时频分析用于区分音色相近或鼓型相同的风格；
3. 808、Log Drum和具体鼓件身份只作为组合证据；
4. Bass行为通常比Bass乐器名称更重要；
5. 人声、和声和制作质感用于区分R&B、Neo-Soul、Jazz-HipHop、Rage等语义型风格；
6. 特征不可用时不加分也不扣分；
7. 第一、第二名接近时输出Top 3并进入人工复核。
