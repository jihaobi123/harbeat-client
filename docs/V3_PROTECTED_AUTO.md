# 自动保护混音 · 2026-09-23

当前保护页默认运行自动声学候选模式，无人工勾选前置条件。人工模式保存在 `manual.html`，冻结 V3 入口继续保留。这个改动修正上一版“所有请求都要人工确认”的产品阻塞；不是把未知情况直接改成安全。

## 使用

选择“已找到可执行窗口的曲对”，点击“自动混音试听（从转场前开始）”。它先准备真实 A、B、变速进入片段，再从混入前 5 秒开始在浏览器实时混音。也可从 A 开头播放并自动接歌，或只播放 A，随后按当前位置请求保护接歌。

当前六首素材可自动规划六组曲对，涉及四首不同歌曲：FREE BRO / RATATA → Cold / Crazy Love，以及 Cold ↔ Crazy Love。Big Girls 与 No Me Tocas 当前未找到合格的自动组合，保留排除原因。六组不是六首连混。

## 自动证据

使用已有报告中的 Demucs 分离人声 50 ms RMS、Silero 活动区间、SongFormer 合并段落、完整拍网格与冻结原曲。分析数据绑定 master 与 vocals SHA，不生成人工 Reviews。

- 人声低活动候选：连续至少 200 ms 的 50 ms 窗口 RMS ≤ -32 dBFS。这是固定工程阈值，未做目标曲库听感校准，不证明歌词语义句末。
- A：不早于模型段尾。在其后两小节内、最多 4 秒寻找低活动间隙；退出点前后至少各 50 ms 落在该间隙内；距相邻小节线不超过 65 ms。实际进入点仍需满足 V3 拍点映射检查。此延后是等候模型段尾的人声尾部，并非人工核准新的结构边界。
- B：枚举同一模型段落内 1/2/4 小节的原曲入口。整个入口直至正文接管后 100 ms 都必须处于低活动区间，且不与原始、未扩展的 VAD 活动区间相交；保留至少 12 秒正文。使用原曲中无人声的材料，避免将分轨残留直接当作无人声。
- 执行：通过上述检查后自动沿用 V3 EQ、淡入淡出及正文恢复原速。A 退出时 B 正文才接管。没有候选时继续 A，没有 18 秒强制退出或普通规划器兜底。

部分自动切点晚于模型段尾，例如 RATATA 108.244 秒模型段尾、110.300 秒声学退出候选。日志明确记录延迟、低活动区间、阈值、原曲与分轨来源。不能据此声称结构标签或歌词乐句已经确认。

## 限制

- 对气声、低音量唱词、分离误差和短暂换气仍可能判断不准，需用户实际试听。自动放行是实验性声学检查，不是安全或音质概率。
- 本轮最长使用 150 秒原演示素材。不是整曲库或整曲覆盖。
- 1 小节转场可能偏短，B 正文恢复原速仍可能有速度变化，沿用 V3 处理，不声称效果已经优于 V3。
- 不参与能量、风格目标。没有合格自动窗口的曲目继续保留人工校正路径。

## 验证结果

140 项源码测试通过，3 项已有可选数据测试跳过；Python 低活动区间测试 2 项通过。真实六组曲对全部在浏览器执行交接，共记录 18 个非零音频渲染观察事件；没有写入任何人工确认。手机宽度无横向溢出，无页面运行异常。此为执行验证，不是主观听感或歌词语义验收。
