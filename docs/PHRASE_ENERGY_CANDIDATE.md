# 乐句与动态 EQ 实验版 · 2026-09-24

页面：`/analysis-lab-static/v32-candidate-20260924/index.html`。这里的 v32 是独立实验目录名，不代表已经确认升级 V3.2。

## 本次改变

原保护版只验证最终退出点附近是否安静，A 仍从 B 进入时就开始全曲渐弱。本版让选点与退场包络共享声学尾音依据：A 在保护尾音之前保持原增益和中性 EQ，之后才退场。B 的伴奏可提前进入，明显人声的开始须晚于 A 保护尾音；不要求 B 整段进入素材都无人声。

先听“乐句保护 + 固定 EQ”，再听“乐句保护 + 动态 EQ”。两者共享选点、素材和增益。旧 V3.1 对照使用原有素材目录和原 `guardPlan`；旧 V3、V3.1 页面、评级键、音频和报告均保留。

## 预处理产物

`analysis_platform/phrase_alignment.py` 联合已有原曲 VAD 与分离人声 50 ms RMS 活动，将间距不超过 300 ms 的活动合并为**声学乐句候选**，追加 80 ms 尾音保护。它不会把短暂呼吸直接变成退出点，也不声称识别出歌词语义句末。VAD 和 RMS 不一致、乐句跨模型段尾的情况保留冲突记录。

- 每个实际小节保存首拍、最后一拍、下一小节首拍；要求观测到 4 拍，缺拍或间隔不一致的小节不能生成退出点。
- 退出点必须晚于保护尾音，并早于下一句；所用时刻为下一小节首拍，**不是将人声裁到最后一拍**。
- “段落＋乐句”模式额外要求模型段尾在该候选结束前一小节内，且没有下一句穿过退出点。它仅表示两类候选相容，不是人工确认的真实段尾。
- “乐句完整”模式允许模型段落内部交接，用户明确选择此模式，不从段落模式自动降级。
- `sourceRows` 是原始 VAD 区间、人声 RMS 帧的一基行号。报告、母带、人声 SHA256 与冻结快照绑定；缺失或不匹配时返回 unavailable。
- 频段数据沿用原始定义：二阶滤波 RMS，低于 250 Hz / 250–4000 Hz / 高于 4000 Hz，滤波带有重叠。存储中的显式 null 对应原分析零功率，缺字段不能当零功率。

本版没有重新训练 SongFormer、VAD 或分轨模型，也没有 ASR／歌词强制对齐。原分轨的漏声、混响和语义上仍未唱完的长呼吸，仍可能影响结果。

## 实时规划与处理

`web/src/phrase/planner.ts` 用当前播放位置搜索至试听素材结束；要求 A 和 B 的来源有效、B 起点不在半句中、B 进入窗口完整位于同一模型段落、速率在 0.8–1.2、变速映射与实际时长一致、接管后还有至少 12 秒素材。

B 首句映射到 A 时轴，须在 A 尾音之后；间距最多 `max(1.2 秒, 120/A_BPM)`。只在通过约束的候选中按等待秒数与人声间距排序，EQ、目标风格和目标能量不参与排名。没有窗口就继续当前曲，并记录拒绝原因。

A 的增益从 1 保持到保护尾音，再线性降到 0；B 从 0 线性升至 1。两路实际基础增益均为 0.76。素材并非预混成品：单曲进入片段提前保调变速，选点、混合和音量／EQ 在 WebAudio 音频时钟实时执行。正文接管后仍恢复 B 原速，这个已有变量本次未改变。

### 两种 EQ 对照

固定版：B 使用低频 −7 dB、高频 +1.2 dB，末段平滑恢复；A 在尾音结束后用 100 ms 接入低频 −9 dB、高频 −1.4 dB。这是尾音保护后的固定参数对照；恢复实现为 dB 自动化，不声称与旧版湿干混合逐采样相同。

动态版：A 的 EQ 保持中性。每 0.5 秒及关键控制点，按源时间窗口读取 A/B 分频段功率，将当时增益平方乘入功率后相加。如果预测叠加超过较强单曲频段功率 0.8 dB，则计算 B 所需衰减。低／中／高频上限分别为 9／4／3 dB，不提升频段，末段平滑恢复。节点间由音频时钟线性插值。

这是**预分析驱动的前馈控制**，不是播放输出反馈测量。二阶分析滤波与播放端 140 Hz 低架、1200 Hz 峰值、3600 Hz 高架滤波并非等价；音轨相关性、限幅器以及保调变速后的频谱差异也会影响实际结果。限幅衰减后不保证预测目标一定达到，必须试听。

## 执行与追溯

时间轴分列模型段落、声学人声、尾音、最后一拍、退出首拍和真实音量包络。EQ 图对应实际调度的控制点。日志记录每一步源区间、频段功率、采样行号、目标、限幅与应用值，并新增“A 尾音保护结束／开始退让”音频线程事件。观察值反映浏览器处理块，不能替代扬声器或蓝牙测量。曲线表示总线限幅器之前的计划增益；新页时钟另记观测时限幅增益与整场最低限幅增益，便于区分计划退场和混合后限幅造成的衰减。

本轮反馈使用独立 `harbeat-phrase-energy-feedback-v1`；原 `harbeat-v31-ratings` 不迁移、不清空。会话继续保存在现有同源 IndexedDB，可从分析平台查看。
