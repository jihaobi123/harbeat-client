# 实时混音决策证据

这次增加可追溯记录，选点公式、保护条件、素材、EQ 和淡化保持原样。六首演示曲的快照与原始分析报告、原曲 SHA256 逐一校验。冻结的 V3 页面保留。

## 页面入口

- `/analysis-lab-static/v3-decision-evidence-20260923/index.html`：自动声学保护模式。
- 同页加 `?mode=v3`：冻结素材上的 V3 普通“下一首”规则，18 秒预算。不提供能量／风格切换，不声称重现旧版全部控制模式。
- `/analysis-lab?tab=mix-debug`：查看本浏览器保存的逐次会话，或导入同事导出的 JSON。
- `/analysis-lab-static/v3-live-baseline-20260922/index.html`：未改动的完整旧 V3。

预览按页面填写的 A 原曲位置计算，试听按钮可从转场前五秒开始播放。播放器会按实际请求时刻重新检查，所以执行计划以对应请求编号下的记录为准。

## V3 实际使用的输入

| 输入 | 普通下一首的使用方式 | 自动保护模式的使用方式 |
| --- | --- | --- |
| 小节网格 | 枚举 A 退出点，反推混入点，允许误差不超过 65 ms | 核验保护点与 B 进入窗口能否同时对拍 |
| 段落起止 | 距任意起止边界小于 0.4 秒，加 0.16 分 | 合并相邻同标签段落；退出须在段尾后，B 入口不能跨段 |
| BPM、变速素材 | rate 必须在 0.8–1.2；较大变速幅度扣分 | 同样限制 rate；先比较完成时间，再比较变速幅度 |
| Silero 人声区间 | 两侧各扩展 0.3 秒，裁剪到窗口并合并；双窗口占比乘积扣分 | B 从入口至正文接管后 0.1 秒不能与未扩展区间相交；扩展占比保留在日志中 |
| 分离人声 RMS | 未用于本次选点 | 精确 A 退出点与完整 B 入口须通过声学间隙条件，阈值不高于 −32 dBFS |
| 整曲风格标签 | 相同标签加 0.04；原模型分数不进入这项加分 | 不参与 |
| 旧相对能量 | 普通下一首仅记录 | 仅记录 |
| 调性、和弦、乐器、鼓组、情绪、动态范围、粗糙度 | 不用于本次排名或 EQ 自适应 | 不用于本次排名或 EQ 自适应 |

普通 V3 分数为：基础分 1，减去等待占预算比例的 0.5 倍、变速偏离 1 的绝对值的 1.4 倍、人声占比乘积的 0.3 倍，再加段落边界、四小节窗口（0.05）、同风格（0.04）奖励。这是人工定义的排序分。

两版都执行固定 V3 EQ 和线性淡化，没有比较多个混音算法后择优。普通版两侧人声占比都至少 5%、并集时长都至少 0.5 秒时，B 中频衰减 5 dB。保护版的入口经过检查，中频保持 0 dB。B 正文接管后恢复原速，目前没有渐进回速。

## 每次混音怎样留下证据

`build_decision_evidence.py` 读取原报告并检查报告文件指纹和原曲指纹。它只附加 `Track.preprocessing` 及解析静态素材地址，不改变分析数值或进入素材。快照保留原数组顺序，界面从 1 开始显示行号，JSON 路径从 0 开始。

`buildDecisionTrace` 将运行时段落关联回原始段落行；合并段落可以对应多行。它列出实际参与计算的人声原区间、扩展区间、裁剪区间及并集；保护版还关联声学间隙内的原始测量帧。前奏中补出的拍网格会与原报告的小节候选区分。

播放器的 `plan_scheduled.trace` 保存本次证据，`decision_search` 保存候选、排序贡献和排除原因。每个事件绑定 `requestId`；素材准备前与准备后搜索分别记录。最终会话包含完整运行输入及预处理快照，主分析平台读取同一份事件，不用新分析结果重建旧决策。

实际混音包含三份文件：A 原曲、B 变速进入片段、B 原速正文。三份文件均记录地址和指纹，区分“用于分析的分轨”与“实际播放的素材”。音频线程记录 B 开始、B EQ 恢复、A 退出三个事件。这里的观察时间是音频处理块时钟，不是扬声器或蓝牙出声时间。

没有保存过的逐帧人声概率显示为未记录。Silero 的 0.5 检测阈值不等于窗口人声概率；时间占比也不等于概率。没有原始快照的旧日志继续显示已有字段，并明确缺少原始行号。

会话保存在同源浏览器 IndexedDB。跨设备查看须导出／导入 JSON；没有新增匿名云端日志写入接口。

## 检查范围

真实目录回归覆盖两个模式各 180 组请求位置，新增快照前后候选内容、排序与计划一致；分别有 156 和 26 组可执行请求。可执行请求逐项核对段落、人声占比和声学测量帧。此检查不证明主观听感或歌词语义边界正确。

建议试听定位时先比较选点和素材，再看转场长度、B 接管回速、EQ 恢复区间。保护版的段尾延后、较短交接和入口变化会改变听感，不能把“人声重叠减少”直接当成“整体更顺滑”。

## 构建与部署

保护／V3 证据页使用 `npm run build:guarded`，把 `guarded.html` 作为独立发布目录的 `index.html`。主平台经现有 `/analysis-lab-static/` 路径提供资源，构建时须使用 `npx vite build --base=/analysis-lab-static/`；默认 `/assets/` 前缀不适合该部署。部署新增哈希资源后再更新入口，保留旧文件，避免已经打开的页面失效。
