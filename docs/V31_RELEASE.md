# V3.1 正式版：原 V3 选点＋动态 EQ

正式入口：[V3.1 实时混音](https://8.136.120.255/analysis-lab-static/v31-live-20260924/index.html)。版本号 `3.1.0`，Git 标签 `audio-v3.1.0`。

用户在 2026-09-24 的小幅调整试听后，明确要求保留认可版本并命名为 V3.1。本次正式采用 `original-dynamic`：原 V3 规划器、原进入素材、完整重叠及渐变增益，加上已经试听的有界动态 EQ。代码来源为 `9e3dacc`，文件与曲库指纹见 [发布清单](releases/v3.1.0.json)。

## 固定的行为

- 使用 `makeV30Planner(false, 'dynamic')`。相邻小节后移实验关闭；段落、实测拍点和声学人声证据仍可查看。
- 原 V3 候选排序、18 秒预算、20 首原曲、152 个进入窗口及变速素材保持原样。
- A 在整个重叠期由 0.76 渐弱到 0，B 同时由 0 渐强到 0.76。B 最后半小节的 EQ 干湿恢复保持原样。
- 动态 EQ 的输入、功率计算、控制点、幅度与变化速度限制全部沿用已试听实现，详见 [EQ 说明](V30_SMALL_TUNING.md#动态-eq-只控制系数)。证据不可用时继续明确报出原因。
- 本次不启用能量／风格重排，也不采用旧保护版或乐句保持版的增益曲线。

正式页面默认打开实时接歌，固定使用已认可方案。原四项对照页面仍可用于固定／动态 EQ 比较。分析平台的内嵌播放器与独立播放入口均指向正式版；历史素材档案及会话仍保持原始来源标识。

## 验证与发布

- 185 项源码测试通过，类型检查和两个生产构建通过。
- 20 组真实案例逐项比较正式规划与已认可分支，包括没有可执行计划的案例。
- 18 组已有反馈对应的计划 ID、进出点、素材区间、变速、重叠长度、每一个 EQ 控制点、原始证据及来源指纹，与推广前保存的重建记录完全一致。这验证实现未变，不替代听感评估。
- 原 V3 规划与评分、动态 EQ 核心、音频线程时钟等七个文件与来源提交逐字节一致。播放器仅新增版本元数据；实际 DSP 调度不变。
- 公网浏览器完成一次用户触发的实时交接，完整重叠 6.426 秒、后移 0 秒，三项音频线程观察齐全，最大时钟偏差 2.835ms；浏览器无脚本报错。这不是扬声器或蓝牙延迟测量。
- 隔离测试浏览器加载原 18 条反馈后逐条核对一致，完成新试听后追加为 19 条，原 18 条未改写；没有操作用户浏览器存储。主平台独立入口与内嵌播放器均通过检查。
- 原 V3、四项对照、旧保护候选三个页面 HTML 指纹部署前后一致。验证结果保存于本地 `outputs/v31-release-20260924`。

构建命令：在 `web` 目录执行 `npm run build:v31-release`。发布目录内把 `dist-v31-release/v31-release.html` 命名为 `index.html`，一并放入构建 assets、音频线程脚本、发布清单以及原四项对照的相同 `catalog.json`、`catalog.json.gz`、`cases.json`。音频继续使用原有 URL，不重新生成素材。
