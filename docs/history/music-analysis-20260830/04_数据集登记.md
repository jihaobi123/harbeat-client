# 数据集与实验产物登记

## 1. 为什么 Git 中没有原始音频

原始商业歌曲、第三方数据集音频、模型权重和逐帧缓存可能受到版权、许可、体积或隐私限制。通常仓库只保存：

- 数据集名称、用途和版本；
- 原始包 SHA-256；
- 下载/解析/评测脚本；
- train/validation/test 或 Fold 划分；
- 聚合指标和模型卡；
- 不含本机路径的匿名 track_id 结果。

本历史分支额外冻结了这次实验的匿名 Embedding、三个 Joblib 分类器和一个许可允许非商业分享的 Discogs-EffNet 权重。任何合作者不得用“Git 中没有音频”推断实验不可复现；应按数据集许可重新获取，并用哈希和划分文件对齐。

## 3. 特征专项验证数据

| 数据集 | 用途 | 主要输出 |
|---|---|---|
| Ballroom/GiantSteps tempo 相关集 | BPM/速度共识 | 直接速度、半/倍速容错 |
| GTZAN beat annotations | Beat/Downbeat 路线 | Beat F1、相位和覆盖 |
| GiantSteps Key | 调性 | Exact/MIREX |
| Groove MIDI Dataset v1.0.0 | 节奏语法 | Backbeat、Breakbeat、Tamborzão、Tresillo、Two-step 等 |
| ENST/鼓转录相关评测材料 | 鼓事件 | Kick/高频事件/鼓件候选 |
| MDB-stem-synth | Bass 转录 | onset/pitch 与派生描述符 |
| OpenMIC/Open Drums 片段 | 808/鼓音色候选 | 身份验证与失败记录 |
| Jamendo Singing Voice Detection | 人声活动 | 帧级 Precision/Recall/F1、密度误差 |
| MIR-1K | 人声音高派生量 | 音域、延音、轮廓 |
| GuitarSet | Chord/Chroma change | 孤立吉他伴奏域和弦变化 |
| MTG-Jamendo 弱标签子集 | 公开风格压力测试 | Funk/Disco/House 弱标签结果 |

精确样本数、阈值和方法以 `config/feature_calibration/v1.json`、`config/model_validation/` 和对应 `scripts/evaluate_*.py` 为准。

## 4. 仓库内实验快照

### style_reference_v0

保存：

- 匿名数据元信息；
- feature schema；
- 艺人隔离 Fold；
- 模型卡；
- 四折指标；
- 稳健性与标签打乱测试；

- 872 个片段和 65 个匿名单曲的 1280 维 embedding 缓存；
- 三个实验 Joblib 分类器与折外预测；
- 未修改的 Discogs-EffNet `.pb` 权重、官方元数据、来源和许可说明；

不保存：

- 原始音频；
- manifest 中的本机源路径；
- 大量逐曲分析 JSON。

二进制位置和限制见 `experiments/style_reference_v0/ARTIFACTS.md`。Discogs-EffNet 权重采用 CC BY-NC-SA 4.0，只能非商业使用；三个 Joblib 文件只能从可信提交加载。

## 5. 数据扩充要求

要进入 21 类正式实验：

1. 补齐缺少 8 类；
2. 每类至少 15–30 首做第二轮路线验证；
3. 每类逐步扩到 50 首以上并加入相邻难负样本；
4. 同曲不同版本、同艺人和高度相似 remix 不得跨集合；
5. 至少两位音乐人复核争议样本；
6. 保留完全不参与模型/阈值选择的独立外部测试集；
7. 对混合风格采用多标签和 out_of_taxonomy，不强迫唯一标签。
