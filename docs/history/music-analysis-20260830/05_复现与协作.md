# 复现、协作与下一步

开始新模块前，还应阅读 [完整工程路线](../../roadmap/01_HarBeat_音乐分析系统_完整实施方案与工程路线.md) 和 [技术背景资料](../../roadmap/02_HarBeat_相关技术原理与成熟状态_背景资料.md)。两份文档是设计目标，不代表所有模块已经实现。

## 1. 环境原则

- Python 依赖见 `requirements.txt`；
- ffmpeg/ffprobe 必须可用；
- 模型路线应通过独立子进程或明确环境隔离，避免 ADTOF、Basic Pitch、madmom 依赖互相污染；
- 模型权重放在外部缓存，不提交 Git；
- 所有输出必须保留 `analysis_method`、`validation_scope`、`validation_status` 和质量标志。

## 2. 69 项特征回归

```bash
python -m pytest app/tests tests -q
```

专项评测入口位于：

```text
scripts/evaluate_ballroom_beats.py
scripts/evaluate_gtzan_beat_this.py
scripts/evaluate_giantsteps_key.py
scripts/evaluate_drum_transcriber.py
scripts/evaluate_bass_transcriber.py

scripts/evaluate_jamendo_vocal_activity.py
scripts/evaluate_mir1k_vocal_pitch.py
```

不要用 10 首真实曲库的运行成功率替代独立数据集准确率。真实曲库只检查模型链完整、缺失、饱和和域误用。

## 3. 13 类风格原型

```bash
python scripts/build_style_reference_dataset.py \
  --zip /path/to/音乐风格参考曲库.zip \
  --output-dir /path/to/style_reference_v0

python scripts/extract_style_embeddings.py \
  --dataset-dir /path/to/style_reference_v0 \
  --model /path/to/discogs-effnet-bs64-1.pb \
  --resume

python scripts/train_style_model.py --dataset-dir /path/to/style_reference_v0

python scripts/evaluate_style_model.py \
  --dataset-dir /path/to/style_reference_v0 \
  --effnet-model /path/to/discogs-effnet-bs64-1.pb
```

先核对源 ZIP SHA-256 和 `track_splits.json`，不得重新随机拆分后直接比较指标。

## 5. 团队分工建议

| 角色 | 首要任务 |
|---|---|
| 数据负责人 | 补齐 8 类、版本核验、艺人分组、人工纯度审计 |
| 特征负责人 | 维护 69 项定义/校准，禁止失败特征跨域升级 |
| 表示学习负责人 | 比较 Discogs-EffNet、MERT、MAEST，先线性 probe |
| 段落负责人 | sections 合同、30 首真值、Boundary/Label 独立评测 |
| 产品/接歌负责人 | 只消费带状态和证据范围的结果，不把候选当事实 |

## 6. 分支协作规则

- 新实验必须提交模型卡、数据哈希、划分、随机种子和命令；
- 指标必须注明评价单位是 frame、event、segment 还是 track；
- 任何阈值调优集与最终测试集必须分开；
- 新模型不得覆盖旧基线，先作为 challenger；
- 失败实验保留结论和配置，不只保留成功结果；
- 二进制模型在对象存储或 release artifact 管理，Git 只记录 SHA-256；
- 不提交音频、本机绝对路径、访问令牌和个人缓存目录。

## 7. 现在开始段落神经网络前的 P0

1. 设计并迁移正式 `sections[]` 数据合同；
2. 保存 All-In-One 原始 start/end/label/source/model_version；
3. 标出 downbeat phase conflict 和 fallback；
4. 建立 30 首人工边界/标签真值；
5. 实现预测导出与 Boundary F1、Bar Macro-F1、Segment IoU；
6. 根据误差决定训练 Boundary Head、Label Head 或完整序列模型；
7. 比较 MERT/MAEST/Discogs-EffNet 的线性 probe，再决定 backbone；
8. 只有独立盲测通过后才允许段落标签影响自动接歌硬决策。
