# 传统/显式 69 项特征历史说明

## 1. 69 项的准确含义

这里的“69 项”是高层输出注册表，包含三种完全不同的对象：

1. 测量量：如低频能量、人声密度、音高范围；
2. 派生关系：如 Backbeat、Tresillo、Bass Syncopation；
3. 语义身份：如 808、Open Hat、Rap、Rage Synth。

三层不能混用。频段能量高只能支持“低频强”，不能自动升级为“808”；检测到人声音高也不等于识别出 Singing/Rap。

## 2. 历史状态

69 项完整注册状态在历史说明中记录为：

| 状态 | 数量 | 含义 |
|---|---:|---|
| validated | 9 | 当时已有满足发布门槛的专项证据 |
| failed_validation | 11 | 做过验证但未达到门槛 |
| provisional | 23 | 有定义和实现，缺少足够专项验证 |
| candidate_only | 20 | 只能作为候选证据 |
| deprecated | 5 | 旧名或误导性语义，保留兼容映射 |
| unavailable | 1 | 当前路线无法可靠提供 |

后续校准文件 `config/feature_calibration/v1.json` 对其中 21 项保存了可引用的 held-out 指标：10 项标为 validated，11 项为 failed_validation。两个统计口径不同：前者是 69 项注册快照，后者是已有独立指标的校准子集。

## 4. 明确失败或不可发布的能力

下列内容虽然可能有原始分数或候选输出，但不能作为风格硬条件：

- Four-on-the-floor：F1 0.7368，未达发布门槛；
- Four-floor stability：F1 0，高 Accuracy 来自负样本占多数；
- Timing quantization：F1 0.2857；
- 808 identity：F1 0.7018，只能保留 timbre candidate；
- Bass staccato：F1 0；
- Bass syncopation、riff repetition：部分指标尚可，但完整发布门槛或链路域不满足；
- Full Snare、Rim、短/长金属打击乐身份；
- Open Hat 的 Open/Closed 身份；
- Rap、Singing、Vocal Chop；
- Jazz/Soul Harmony；
- Electronic/Acoustic/Lo-fi/Rage Synth 身份；
- 商业混音 other stem 上的和弦变化硬判定。

## 5. 为什么关系特征必须单独验证

Kick 和 Bass onset 各自误差不大，二者相减后仍可能把真实 70ms 间隔错误变成 5ms。因此：

```text
底层事件通过 ≠ 事件关系通过 ≠ 语义身份通过
```

代码用 `analysis_method`、`validation_scope`、`validation_status` 和 `style_required_allowed` 防止验证结果跨路线继承。例如 GuitarSet 只验证孤立吉他伴奏，商业歌曲 Demucs other stem 使用不同方法名，不继承 validated。

## 6. 实现结构

| 模块 | 责任 |
|---|---|
| `feature_registry.py` | 定义 measurement/derived/semantic 与默认 fail-closed 状态 |
| `feature_calibration.py` | 加载版本化指标并执行发布门禁 |
| `rhythm_feature_analysis.py` | 小节网格、节奏模板和节奏关系 |
| `bass_feature_analysis.py` | 低频音符、运动和候选音色 |
| `percussion_feature_analysis.py` | 打击乐家族候选 |
| `vocal_pitch_analysis.py` | 音高、音域、延音、轮廓 |
| `musical_context_feature_analysis.py` | 和声、音色和制作上下文 |
| `acoustic_measurement_analysis.py` | 客观声学测量 |
| `feature_model_adapters.py` | 外部模型结果适配、状态与失败隔离 |

## 7. 对风格识别的历史结论

69 项显式特征仍然非常重要，适合：

- DJ 接歌约束；
- 解释模型为何推荐某风格；
- 人工审核和错误定位；
- 与 embedding 融合；
- 生成候选和质量标志。

但它们不应单独承担 21 类主分类。详见 [传统规则与 ML 配对报告](../../../experiments/traditional_vs_ml_20260829/reports/traditional_vs_ml_assessment.md)。
