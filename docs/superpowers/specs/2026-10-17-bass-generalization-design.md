# 第四轮：贝斯交接覆盖验证与低频 EQ 对照

用户确认按六组三版盲听继续：旧样例 Attention→HIPHOP，加五个新曲对。每组冻结选歌、完整原计划、速度映射、进出点和人声检查。先不上线，不把小样本偏好解释为普遍有效。

## 样例和资格

从当前 148 首曲库的来源绑定快照中读取原有安全候选。旧样例完全沿用上一轮。五个新来源槽位预先固定，按以下顺序找第一个满足来源、原拍点/人声/素材/EQ 和连续两小节贝斯交接资格的来源：

- EDM：The Spectre、Nevada、Move Up (Lost Gravity)。
- KPOP：After LIKE、꽃 (FLOWER)、Movie Star。
- amapiano：Yensa、Big Flexa、Hamba Nobani。
- funk：24K Magic (1)、Let's Groove、Treasure (1)。
- jazz hiphop：Love Note (Original Instrumental)、Ampersand、Playback (feat. Ine)。

只接受既有原始计划，不移动接点。每个目的曲保留通过新增交接资格的最高原分计划，再使用已确认的实验调性偏好排序（仍是待复核标签）。同槽位的目的候选按既定排序顺序检查，不按试听成功挑样例。记录所有跳过原因、来源与风格标签、速度、交接时长、贝斯能量。分离贝斯过弱、缺文件或无法覆盖时如实缩小样例，不补造结果。五个新曲对不得重复旧例，尽量不重复来源或目的曲。曲库/风格标签是原有标签，不当成经过验证的曲风真值。

## 三个处理臂

1. 原渐变：现有增益与动态 EQ。
2. 独立贝斯：沿用已通过试听的 A 贝斯轻收、最后一拍交接、下一小节由 B 贝斯提前承接；其余声部增益保持参考版。使用 master×G+bass×(B-G) 的滤波后补偿。
3. 低频 EQ：保持参考版整曲增益和原 EQ，另加每侧 140 Hz lowshelf，最多额外削减 18 dB。A 在同一 duckStart 到 swapStart 从 0 到 -6 dB，再到 swapEnd 为 -18 dB；B 在 swapStart 前为 -18 dB，至 swapEnd 恢复 0 dB。这个设置对所有曲对固定，不逐曲调整。它会影响该频段里的鼓与其他声音，不是纯贝斯替换，也不声称与分轨版逐频率/逐响度等价。

三版同一原接点和干湿/EQ基础曲线，独立贝斯和 EQ 在同一实测交接标记干预。三版共享同一批四通道同步 master/bass 片段和原时刻的 B 原速正文。原固定 EQ 节点、附加低架节点、总输出与限幅链在三臂同构；非 EQ 臂的附加低架增益为零。不得按臂单独归一化或补偿音量；记录声音更响/更轻的听感以识别偏好混杂。明确这不是经过等响校准的实验。

## 盲听与记录

每组 A/B/C 映射随机且在一轮内固定；六组采用平衡置换，每种方法出现在每个字母位置两次。页面播放进度不泄露方法，初次偏好记录前不显示方法和曲线。三版都完整播放后才可选择偏好，记录初次盲听选择、后续修改和揭晓时间。支持“差不多”和“都不理想”。揭晓后展示方法解释和设置；初次选择不可被后续改票覆盖。

记录低频清楚、底鼓变弱、低频变空、交接突兀、人声变糊、声音更响/更轻等现象和备注。每轮保存在本机；导出包含原始选择、映射、完整播放日志和来源。新一轮保留旧轮记录，并重置盲听映射与听完状态。QA 完成后给用户留下新的未揭晓一轮。

六组只帮助初步识别适用范围及失败样例，不能代表全曲库、全部曲风或长期自动播放。报告每个样例与现象，旧样例单列为已听过的锚点，不能当成独立新样本。网页与之前试听页独立，生产默认不变。
