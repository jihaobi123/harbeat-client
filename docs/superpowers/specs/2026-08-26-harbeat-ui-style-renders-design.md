# HarBeat 移动端 UI 多风格渲染设计

日期：2026-08-26

## 最终交付内容

根据第二轮评审，最终交付收敛为 3 张横向 UI 展示图：叙事插画、瑞士信息网格、新粗野插画。每张图并排放置 4 个正面手机界面：首页、音乐、设备、我的。只交付渲染图，不制作可运行页面。

图片保持相同画布比例、手机尺寸和页面顺序，方便逐套比较。画面不出现手、持机人物或场景道具。六套方案不能只在现有页面上换色、换字体或叠加插画；每套都要重新建立信息层级、空间节奏和组件关系。

## 不变的使用方式

所有方案沿用现有产品手册中的信息架构与交互含义：

- 底部导航固定为首页、音乐、设备、我的。
- 迷你播放器固定在底部导航上方，保留曲名、BPM、播放进度和上一首、播放、下一首。
- 首页保留设备状态、正在准备的 Cypher、手机播放和连接设备两个快捷入口。
- 音乐页保留推荐、搜索、曲库、歌单四个分区，以及歌单编辑、新建歌单等操作。
- 设备页保留 RK3588 在线状态、Main Out / Stereo、延迟与曲目等事实、Pad 预设、测试音和配对入口。
- 我的页面保留舞者画像、画像控制和使用记录。

视觉方案可以重新组织页面区块、组件形态和视觉动线，但不能删除功能、改名底部导航或改变操作结果。交互流程不变，屏幕几何不要求照抄现有截图。

## 流程保真要求

渲染图必须以 `harbeat-mobile-product-handbook.html` 为唯一交互依据。首页继续承担推荐与设备入口；音乐页内部仍是推荐、搜索、曲库和歌单，并保留歌曲详情、试听、保存、合法资源匹配和导入入口；设备流程仍按设备列表、四位配对码、设备面板、Pad 编辑、确认覆盖并同步的顺序组织。

在线、离线、连接中、配对码错误、App 与设备版本不一致、同步完成等状态不能互换含义。Pad 先保存 App 版本，再由用户明确确认覆盖 RK3588；固定核心按键仍不可编辑。活动 Session 的现场操作不写入个人推荐画像，个人页继续呈现这层边界。

最终图片是静态渲染，无法演示点击后的动画和状态切换，但页面上的入口、按钮文案、状态提示与去向必须和 HTML 一致。四个主页面要让用户看得出完整流程从哪里进入、下一步去哪里，不能为了风格简化掉关键动作。

## 设计深度与视觉锚点

每套方案先建立一条自己的版式语法，再设计组件。配色只是结果，不是风格本身。

- 新粗野主义以“舞台施工标识”为锚点。大标题、状态条、控制区和内容卡采用错位模块、编号、压边与工业标签组织，主操作可以跨越网格，但点击边界必须清楚。
- 平面编辑插画以“舞者动作的连续分镜”为锚点。插画负责引导视线和解释功能，推荐、歌单、设备连接与个人记录分别形成不同的叙事画面，不把插画当作卡片贴纸。
- 夜场信号以“从手机到 RK3588 的信号路径”为锚点。连接状态、输出、同步和播放沿一条发光信号脊柱展开，页面层级由节点、波形和通道路由表达，而不是重复矩形卡片。
- 瑞士节拍以“音乐档案索引”为锚点。编号、坐标、基线与留白决定页面结构，信息主要靠字号、位置和细线分组，减少传统卡片。
- 液态数字以“声音在空间中的流体形态”为锚点。主要任务依附在大块彩塑表面和层叠景深上，页面使用浮动 Dock、焦点球体与连续曲线建立动线，信息层仍保持稳定对比。
- Y2K 数码俱乐部以“复古媒体操作系统”为锚点。页面由可重排窗口、播放传输条、像素表头和金属控件构成，使用层级来自窗口关系与工具栏，而不是在旧版卡片上增加扫描线。

## 最终三套配色规则

叙事插画以暖纸白和深墨色为基底，约占画面八成。钴蓝与橙色负责两个主要内容章节，粉色只标记当前操作或运动轨迹，绿色只表示设备在线。单个页面最多出现三个高饱和色，插画区域可以丰富，文字承载区必须收敛。

瑞士信息网格以白、黑和灰为主。国际蓝只标识当前模块、编号与可继续的主路径；信号红只标记需要注意的次级状态；荧光绿只保留给播放器的播放状态。颜色不能替代网格和字号层级。

新粗野插画使用奶油纸底与黑色结构线。酸性荧光绿只用于在线状态和主操作，钴蓝用于主要内容，橙红用于次级动作或 Battle 内容，粉色只在插画运动轨迹中少量出现。高饱和色要形成冲突，但不能平均分配；正文优先使用黑字白底或白字黑底。

三套都遵守同一可读性规则：页面只保留两到三个主要字号层级；最亮的颜色只给当前最重要的动作；次要信息降低饱和度而不是缩到难以阅读；关键文字与底色保持明确明度差。

## 六套风格

### 1. 新粗野主义

奶油纸底、粗黑描边、硬投影和方正卡片。主色为酸性荧光绿、钴蓝和橙红。大字号标题与高对比标签延续街舞海报的直接感，参考用户提供的新粗野主义设计系统。

### 2. 平面编辑插画

白色底面配黑色手绘线，使用黄色、天蓝、粉色和橙色平涂色块。舞者、音箱、唱片与节奏动作以编辑插画的方式进入卡片背景，但不遮挡按钮和数据。参考用户提供的杂志插画版式。

### 3. 夜场信号

深黑背景配紫外光、电光青和荧光绿。波形、信号线和微弱网格用于表现现场状态。透明层只放在装饰和次级状态区域，正文与按钮保持实色高对比。

### 4. 瑞士节拍

白色或浅灰底，使用严格网格、巨大无衬线标题、信号红和国际蓝。信息按编号、细线和对齐关系组织，强调快速扫描，整体接近独立唱片设计与现代导视系统。

### 5. 液态数字

浅色珠光渐变、半透明彩塑卡片、圆润几何与少量铬感高光。主界面保持明亮、轻盈，文字承载区域使用实色或高遮罩层，避免渐变削弱可读性。

### 6. Y2K 数码俱乐部

深紫底搭配亮粉、电青和荧光黄。使用叠影标题、扫描线、复古播放器符号和小面积金属质感。装饰集中在顶部标题与卡片边缘，功能按钮仍保留明确的点击边界。

## 四个页面的画面内容

首页显示 "MAKE THE FLOOR MOVE."、RK3588 在线状态、"今晚的 CYPHER"、继续准备，以及手机播放和连接设备。

音乐页显示推荐、搜索、曲库、歌单四个入口；主内容使用 "本周练习" 和 "BATTLE WARM-UP" 两张歌单卡，并保留编辑、删除、新建歌单。

设备页显示 "READY MEANS READY."、RK3588 在线状态、Main Out / Stereo、Pad 预设 "CYPHER FUN"、播放测试音和使用配对码连接。

我的页面显示 "YOUR TASTE. YOUR RULES."、FENG / DANCER、画像控制说明和一条 Cypher Session 使用记录。

## 渲染规格

- 每套是一张完整大图，4 台手机从左到右排列。
- 手机正面视角，屏幕内容完整，四台设备不重叠。
- 中文为主，保留现有必要英文标题与设备术语。
- 关键中文、页面标题、按钮和状态文字需要清楚可读。
- 不添加新功能，不出现网页浏览器边框、设计软件界面、手、水印或额外品牌标识。
- 六套图的构图、页面顺序和信息量一致，差异集中在视觉风格。

## 验收标准

每张图都能辨认出首页、音乐、设备和我的四个页面；底部导航与迷你播放器完整；六套风格互相独立；参考风格只吸收视觉特征，不复制原图内容；最终只交付位图渲染结果。
