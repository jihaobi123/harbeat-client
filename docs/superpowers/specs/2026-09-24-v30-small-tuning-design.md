# V3.0 小幅边界校准与独立 EQ 对照

用户明确要求基于 V3.0 小幅调整并执行，保留长时间渐变听感；不再使用先保持 A、尾音后短时退出的保护模式。本轮按这项授权实施，不增加设计确认步骤。

基线为原 20 首 `v3-catalog.json` + `planNext` 普通 next 请求 + 原始播放器固定 EQ 分支。不得使用 V3.1 / phrase 的新增短入口，不增加等待预算，不用无人声约束排除原方案。原选择歌曲、B 素材、变速率、转场时长和整段线性增益保留。

边界校准是独立派生层：联合既有声学活动与实际拍网格，标记切到人声中间、模型段尾距离和缺拍风险。只在原 V3 选定 B 窗口后比较当前退出点及下一个相邻小节首拍；后者必须已在原 V3 合法候选中、具备完整实测小节、确实降低人声截断风险或改善段尾对应，才将开始／结束一起后移同样距离。转场长度不变，最多一小节，仍在原 18 秒预算内。证据缺失、冲突或未改善时原样保留，并显示原因。声学候选不是语义识别精度提升证明。

EQ 是独立开关：固定版走原 V3 调度路径；动态版完全保留原 V3 gain、A 湿声20ms启用、B最后半小节湿干恢复，只把原 EQ 设定值变为随本地频段功率、重叠位置与两曲人声活动变化的平滑参数。参数围绕原模板小幅变动、低高频偏移最多3dB、中频最多2dB，变化速度上限3dB/s。无可校验能量则拒绝动态模式并显示固定选项，不隐瞒替代。不得复用上一版在互补线性增益下几乎不会触发的总功率阈值算法。

页面采用 2×2 对照（原始／微调选点 × 固定／动态 EQ），显示原退出、微调退出、完整转场时长和真正增益曲线；动态曲线和源频段数值可查看。用20首原试听样本并保留无法规划的结果，可在播放中触发。旧页、音频、分析报告和偏好不改。新页独立命名 `v30-tuning-20260924`，新反馈键隔离。
