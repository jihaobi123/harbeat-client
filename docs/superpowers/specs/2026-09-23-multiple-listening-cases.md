# Multiple listening cases per independent experiment

The user requests multiple songs for every trial to avoid single-pair bias. This extends the approved single-variable comparison design; implementation remains within that authorization.

Provide 12 selectable cases per direction from the existing six-track catalog, with all six tracks appearing as outgoing tracks in ranking cases. Fixed four-bar cases require a valid half-length grid and matched-rate alternate; five outgoing tracks pass, and all six tracks occur across both decks. Ranking experiments include fixed early/later triggers and explicitly retain unchanged and unavailable outcomes. Fixed DSP/material/length cases use different directed pairs, equal-duration/rate material alternatives, and source-verified half-length tails. Do not change weights, detector, ordinary transport, or frozen V3 assets. No claim that the small mostly-vocal library represents all music.

Each case displays track pair, trigger, source windows, measured vocal occupancy and section labels, whether plans actually differ, and feedback attached to immutable case/plan identity. Switch case clears note/rating; completed feedback for one case must not unlock another. Keep the legacy fixed example available. Publish a new independent release and make the current experimental entry link to it; preserve original experiment backup and frozen V3.
