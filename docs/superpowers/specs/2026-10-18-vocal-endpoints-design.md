## Alternatives and selected design

Use existing Silero source-bound intervals as one seed, official Essentia YAMNet voice/instrumental plus singing/rapping event scores as coarse corroboration, librosa pYIN and envelope as local sustain/tail evidence. CREPE is researched as an alternative but not added in parallel. Run all analysis on bound separated vocal tracks; no claims that full-mix calibration transfers to stems. New thresholds remain provisional.
