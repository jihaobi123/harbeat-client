# Flow Wrist QMI8658 手势测试

日期：2026-08-27
状态：驱动与安全状态机已完成，佩戴阈值还需现场校准。

## 当前实现

- QMI8658 与触摸、电源管理共用开发板 I²C 总线，地址 `0x6B`。
- 加速度范围 ±8g，角速度范围 ±512dps，采样率 125Hz。
- 初始化失败只关闭手势，不影响屏幕、触控或 BLE。
- 所有手势命令复用触控的 CBOR/Command indication 路径，不存在第二套业务状态。

完整操作顺序：

1. 先抬腕或移动手腕，再稳定 500ms；长期放在桌面上不会进入 READY。
2. READY 后 3 秒内做一次左右双向 roll，进入 5 秒 ARMED 窗口。
3. 向上 flick 选择 ENERGY，向下 flick 选择 STYLE。
4. 左右 roll 每次只预览一档。
5. 保持稳定 800ms 出现确认，累计 1.1 秒才发送。
6. 触摸屏幕、BLE 非 READY、Hub locked、超时或错误方向动作都会取消。

## 已完成的自动测试

- 30 秒持续舞动合成轨迹：`ARMED = 0`，`SEND = 0`。
- 能量 next、风格 prev、1–5 边界、四风格边界通过。
- 触控抢占、BLE 断开、Hub locked、5 秒超时和 350ms 冷却通过。
- 模拟版与真实 BLE 版构建通过。

## 现场验收门槛

- 能量 +1、能量 -1、风格 next、风格 prev 各做 10 次，成功率至少 90%。
- 正常舞动 10 分钟，误发送必须为 0。
- 任意手势阶段触摸屏幕，触控必须立即接管。
- Hub 正在切歌或断线时，手势不能改变预览，也不能发送。

如果出现误发送，先提高双向解锁的主轴比或延长确认静止时间；如果漏检，先调整 flick 的持续区间。不要取消“双向解锁 + 稳定确认”这两道门槛。
